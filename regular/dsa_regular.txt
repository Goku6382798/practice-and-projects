📘 DSA Theory (Core Concepts)
1. Asymptotic Analysis

This is how we measure the efficiency of algorithms:

Big O (O) → Upper bound / worst case.
Example: Linear search → O(n).

Big Ω (Ω) → Lower bound / best case.
Example: Linear search best case (first element) → Ω(1).

Big Θ (Θ) → Tight bound / average case.
Example: Linear search average → Θ(n).

👉 Always focus on Big O in interviews (worst case).

2. Common Time Complexities

O(1) – Constant → Array index access, hash lookup.

O(log n) – Logarithmic → Binary search, balanced BST lookup.

O(n) – Linear → Traversing an array or list.

O(n log n) – Log-linear → Merge sort, Quick sort (average).

O(n²) – Quadratic → Bubble sort, nested loops.

O(2ⁿ) – Exponential → Recursive Fibonacci (without DP).

O(n!) – Factorial → Travelling Salesman brute force.

👉 Rule of thumb:

n ~ 10⁶ → O(n log n) is OK.

n ~ 10⁴ → O(n²) might still pass.

n ~ 20–30 → O(2ⁿ) acceptable for recursion/backtracking.

3. Space Complexity

Measures extra memory required.

Includes:

Variables

Input storage

Auxiliary structures (stacks, hash tables, recursion stack)

4. Recursion Basics

A function that calls itself until a base condition.

Uses the call stack → each call stores parameters + return address.

Can cause stack overflow if base case is missing.

👉 Tip: Convert recursion to iteration when possible for efficiency (tail recursion).

5. Algorithm Design Paradigms

Divide & Conquer – Break into subproblems (Merge Sort, Quick Sort, Binary Search).

Greedy – Make local optimal choices (Activity Selection, Huffman Coding).

Dynamic Programming – Store subproblem results to avoid recomputation.

Backtracking – Try all possibilities, prune invalid ones (N-Queens, Sudoku).

6. Data Structure Trade-offs

Array vs Linked List:

Array = O(1) access, but O(n) insertion.

Linked List = O(1) insertion, O(n) access.

Stack vs Queue:

Stack = LIFO.

Queue = FIFO.

Hash Table:

O(1) average for search/insert, but O(n) worst case (collisions).

Trees/Heaps:

Balanced BST = O(log n) insert/search.

Heap = O(log n) insert, O(1) get min/max.
