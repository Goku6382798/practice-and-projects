Lets suppose we have a table with following columns
  order_id, order_date, customer_id, customer_name, customer_email, product_id, product_name, product_category, quantity, unit_price, payment_type, country, last_updated  

We add the data as per incremental load

So lets start creating the data modelling as per the above columns we will do it one by one

Dim_customer:-
customer_id, customer_name, customer_email, Dimcustomerkey(and add a surrogate key because the customer_id can be weird which we will hard or typical to use and remove duplicates)

Dim_products:-
product_id, product_name, product_category,Dimproductkey(Same reason which was in customer)

Dim_payments:-
payment_type, Dimpaymentkey(Same reason which was in customer)

Dim_region:- 
country, Dimregionkey(Same reason which was in customer)

And one big table without the facts like quantity, unit_price which we will be using inside the fact table

Dim_sales:-
order_id, order_date, customer_id, customer_name, customer_email, product_id, product_name, product_category, payment_type, country, last_updated, Dimsaleskey(Same reason which was in customer)

While creating the Fact table we will use all the Dimkeys that were created inside dim tables
FACT Table:-
Dimcustomerkey, Dimproductkey, Dimpaymentkey, Dimregionkey, Dimsaleskey, quantity, unit_price

Below is the query for more understanding:-

SELECT
 Dimcustomerkey, 
 Dimproductkey, 
 Dimpaymentkey, 
 Dimregionkey,
 Dimsaleskey, 
 F.quantity, 
 F.unit_price
FROM
 datamodeling.silver.silver_table F
LEFT JOIN
 datamodeling.gold.dimcustomers C
 ON F.customer_id = C.customer_id
LEFT JOIN
 datamodeling.gold.dimproducts P
 ON F.product_id = P.product_id
LEFT JOIN
 datamodeling.gold.dimregions R
 ON F.country_id = R.country
LEFT JOIN
 datamodeling.gold.dimpayments PY
 ON F.payment_type = PY.payment_type
LEFT JOIN
 datamodeling.gold.dimsales S
 ON F.order_id = S.order_id
